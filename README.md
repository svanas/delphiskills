### Prompt per session:

`Before reviewing, writing, refactoring, or compiling Delphi code, read https://github.com/svanas/delphiskills/blob/main/skill.md and follow it.`

Works in Claude Code, OpenAI Codex, or any other agent.

The skills support Delphi 11 and newer. One of the sources is about Delphi 5 but got annotated in 2025 with information about the latest version.

### Sources:

- *Object Pascal Handbook*, Delphi 11 Alexandria edition (2021)
- *Expert Delphi: Robust and fast cross-platform application development*, Marco Cantù and Paweł Głowacki (2024)
- *Mastering Delphi 5*, Marco Cantù, 2025 annotated edition (release 0.2, February 17, 2025)
- *Code Faster in Delphi*, Alister Christie (2020)
